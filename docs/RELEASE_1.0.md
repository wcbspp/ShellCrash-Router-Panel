# 1.0

AX5和K2P的统一维护版本。日常管理仍在路由器原后台，电脑只在安装、更新和准备离线文件时使用。

## 这版的变化

- 两机统一下载安装向导，可先检查环境；已下载的安装包也能准备可带走的离线文件夹。
- 节点按实际策略组显示，单次内核HTTPS测试与按需Ping分开，页面说明使用同一口径。
- 恢复前核对完整组件、机型和内核，执行还要原生预检、二次确认与短期单次票据；断线后可查询同一任务结果。
- K2P受限流式升级与启动文件描述符交接修复；AX5按实际解压大小核算安装和升级预算。

两机已做真实新装、跨版本升级与现场恢复，保留配置和节点选择。Wi-Fi与物理断电启动沿用已有实测。电脑安装向导的测试和设备本身的验证分别记录。

## 使用范围

支持README列出的硬件与固件，不包含刷机、其他型号或所有Padavan分支。全局模式覆盖本项目接管的IPv4 TCP，不是全协议VPN。K2P不支持SSR，也不提供第三方订阅转换。

本轮AX5 16路真实代理连接维持半小时；K2P加到23路约6分钟后触及测试安全余量，主动停流。配置与核心进程保持，没有新增OOM，但这不代表64路持续高负载已通过。

完整连续24小时和部分业务边界未全部覆盖。本次按使用者决定结束等待，保留这些限制。关闭KSpeeder后的长期表现也不据此额外保证；不能把所有历史白天故障都归为同一原因。

发布包不含用户订阅、密码、设备身份、内核二进制或路由器固件。内核在在线安装或离线准备时从固定上游下载并校验。
