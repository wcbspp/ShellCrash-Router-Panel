# 国内直连加速与规则页验收记录

本轮源已部署到两机，尚未发布。验证对象是新增开关、模式联动、规则页说明和流量口径；不能替代整项目所有菜单、按钮及上线场景验收。

## 最终设计

用户确认：自定义国外代理规则不应一律阻止加速。已改成可开启：国内 IPv4 在防火墙优先直连，国外 IPv4 继续执行内核规则。提示国内 IP 上的代理或拦截规则会被跳过。保留纯 Fake-IP、无法识别配置、内存/数据校验保护。

首页统一叫「内核累计」，旁边按实际状态显示「当前含直连」「国内绕过中」「全局代理中」「接管已暂停」。累计保留本次内核启动以来的原始计数，不能重新解释成纯代理用量。

规则维护改成「直连数据更新」。国内 IP 表、域名库、订阅规则分开说明；按钮说明指出更新范围及是否需要重启，细节折叠。AX5 当前完整 Mihomo 模板的国内 IP 表支持热刷新；K2P 新表仍需要配置重载。

## 实机结果

- AX5：1200 px、390 px 的开启、关闭、草稿保持、规则/全局/直连联动和恢复通过。自定义规则存在时可开启，警告可见。最终轮每一步 PID 保持相同，无内核重启、页面脚本异常或水平溢出。
- K2P：最终轮两端状态、关闭、手机开启/关闭及桌面模式联动通过，PID 30205 保持相同。最终轮桌面初始已开启，不能把这轮记录当作桌面开启按钮的全新完整验收。早先桌面按钮确实提交成功，但测试脚本只等 30 秒，未等到 Storage 写入完成；原始超时记录保留。
- 国内绕过规则位于 DNS、私网和内核标记排除之后、透明接管之前。K2P 实际 LAN 防火墙计数：TCP 28→45 包，UDP 220→591 包；只能证明国内连接命中了绕过，不证明全部计数来自游戏，也不证明游戏延迟降低。
- K2P 国内表包含 8.153.13.81，不含 8.8.8.8。路由器自己的 curl 不经过 LAN 接管链，先前的 OUTPUT 链探测不能作为 LAN 绕过证据。
- 两机测试结束恢复规则模式与关闭绕过；核心配置、订阅、域名分流、DNS 例外和内存预算按本轮源码部署前指纹核对一致。没有用远端备份覆盖配置。
- K2P 本轮 Storage 写入约 518846 字节，低于 524288 字节限制，余量很小。源码需继续控制体积。

## 发现并处理的测试问题

部署脚本初次没有保留 shell 执行权限，K2P 状态接口为空。已修复部署步骤及实机权限；这期间内核继续运行。截图定位匹配多个 section、旧登录响应导航竞态和闪存等待时间属于测试脚本问题，失败记录不算产品通过。K2P 发现其他局域网 Web 客户端后停止等待，经用户确认关闭其他页面，再继续单会话测试。
