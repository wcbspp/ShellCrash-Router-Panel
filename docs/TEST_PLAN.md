# 上线前测试

控件与场景清单共 424 项（AX5 220、K2P 204），桌面与窄屏各保留一个执行位，共 848 个执行位。每项都有前置条件、具体步骤、预期、失败边界、证据和恢复要求。清单见 CONTROL_TEST_CASES.csv，实际状态见 CONTROL_TEST_RESULTS.csv；继承的部分通过记录不能替代统一安装包验收。

| 节点 | 所有策略组、嵌套组、自动择优、固定节点、全节点模糊搜索、协议、分页、延迟超时、跨面板选择同步 |
| 四项分流 | 单项/四项草稿、统一保存、取消、全部跟随、节点消失、失败不丢草稿、真实目标命中 |

## 证据

记录任务阶段、错误信息、PID、配置 SHA、策略当前选择、防火墙/新连接链、DNS结果、内存与Storage、页面截图。证据中订阅、密码、MAC、序列号、SSID、位置与身份密钥不公开。截图不把后台显示成功当成唯一证据。

每次有状态修改先记录用户当前设置；测试后恢复，并核对恢复结果。K2P 测试只用一个管理客户端，避免旧会话导致虚假超时。

## 发布门槛

所有 P0 用例必须通过；P1 无未说明失败。两机的安装、升级、备份、恢复和重启必须有当次实际证据。离线构建与单元回归通过仍不足以公开稳定安装包。无可用干净测试设备的首次安装应标待执行，不能把模拟环境等同于实机。
