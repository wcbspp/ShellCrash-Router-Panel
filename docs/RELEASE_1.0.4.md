# 1.0.4

- 监控页检测到 ZeroTier 时才显示对应卡片。TUN 兼容设置放在卡片内，支持识别符合条件的自定义持久目录。启用和撤销保护时会保留原有配置字段。重启 ZeroTier 期间，连接可能短暂中断。
- 规则缺失时，先找持久存储和已配置的 WebDAV 缓存，再从上游直连获取。原版本找不到时，适用的规则会尝试同源兼容版本并记录新摘要。本机代理只有在已就绪时才参与兜底。
- 主页状态区显示当前安装的面板版本，内核版本仍在原位置。
- 订阅卡片的进度条改为显示剩余比例，和余量数字一致。
- 修复更新回退、恢复任务清理和操作锁的边界。回退失败时保留恢复所需的文件。AX5 首次安装中途失败时清理本次写入的目录。

AX5 和 K2P 各做了一次真机重启。原配置和节点选择保留，代理 HTTPS、ZeroTier 双向连通及 K2P 到 AX5 的管理访问均通过。失败分支在设备的隔离目录内验证，包括恢复任务的清理与留证。本轮使用原现场配置核对重启，整包 WebDAV 覆盖还原沿用既有实测记录。

已有面板请走[更新入口](DEPLOYMENT.md#已有面板怎么更新)。新装请先确认机型和固件，再选对应的在线或离线安装方式。下载后的文件可用随附的 `SHA256SUMS` 核对。
