# 重启、业务按钮与远端备份验收

本轮保持用户当前配置；未从远端恢复配置。AX5、K2P 各通过页面重启一次内核，没有重启路由器。K2P 使用一个 Web 管理客户端，每组测试结束关闭浏览器会话。

## 已找到的问题

- K2P 此次用户整机重启后，内核在系统运行约 134 秒时启动。墙钟在开机联网后校正，不能用跨校时的日志差值推算启动耗时。旧流程同时包含内核获取、国内域名库公网下载和用户此前设置的 30 秒延迟。
- 国内域名库一次公网下载等待 40 秒。原钩子只识别旧 HTTP 镜像地址，没有调用 WebDAV 对象下载；应用备份与这个独立的启动资源缓存不能互相代替。现在使用 RAM 已校验文件 → 启用且验证过的远端对象 → 原公网源；文件须符合固定 SHA。同步备份时也补齐该小文件。没有增加驻留服务。
- ShellCrash 原延迟位于启动准备和下载之后。K2P 开机路径现在先等待配置中的启动延迟，再获取资源；传递已等待标记，避免之后重复等待。不更改用户设置。实际设备本轮读取到 start_delay=0；10 秒顺序与去重通过离线执行测试，尚未再次整机重启计时。固定等待不保证网络一定就绪，下载仍保留超时、校验及回退。
- K2P 启动后的分流钩子缺少完整 PATH、运行目录和 LAN API 初始化；早期页面查询还可能缓存“防火墙尚未创建”。已修正钩子，并允许此状态在链出现后重试。实机不重启应用后，TCP/UDP 国内绕过规则均恢复；配置和 PID 不变。
- K2P 普通重启原先未保留 RAM 中已解除链接的可执行文件。现在先验证版本并持有文件描述符，再停止、启动。实际重启日志记录复用执行文件，无内核包下载。
- 备份页只显示 RAM 中的远端索引缓存，重启后误报无备份。实机远端应用索引实际返回 200，独立配置索引返回 404。已增加首次进入备份页的远端查询和“刷新记录”；查询失败保留同源记录并显示错误，只有真实 404 才显示无记录。关闭或未验证不连接；查询不轮询。

## 本轮实机范围

两机分别在 1200 与 390 像素宽度执行：八个标签页、四项分流同时编辑和取消、草稿经状态刷新保留、跟随订阅的草稿取消、全节点模糊查询与无结果、策略组导航和分页、刷新、三种运行数据查询和筛选、日志来源、内存历史刷新。每机记录 47 组业务结果。四项分流的实际保存、异常回退等未在本轮全部覆盖。

实际重启按钮：AX5 PID 1904 → 32250，K2P 5405 → 22499；已运行 API、规则模式、策略选择均确认。两机新的订阅余量查询时间和启动事件标识更新。K2P 持久配置 SHA 保持；其国内绕过请求保持开启并恢复有效。

用户确认本轮重启后：AX5 Wi-Fi 的 ChatGPT 与 172.22.22.22、K2P Wi-Fi 的国内网站与《小冰冰传奇》均正常。此确认不等同于所有模式、全部协议、游戏延迟改善和长期稳定性通过。

K2P 自然 LAN 流量的国内绕过计数：TCP 10 → 12，UDP 577 → 778。证明存在实际命中，不能据此推断全部游戏连接或性能提升。

高级面板两机实际加载、四档缩放、窄屏布局、返回刷新均通过，PID 不变。本轮未完成高级面板所有动态写操作。

本地导出两机两种屏宽均成功，gzip CRC、归档路径通过；AX5 约 1.51 MB / 229 个成员，K2P 约 237 KB / 162 个成员。未把下载与校验等同于应用恢复测试。

## WebDAV 实机证据

K2P 当前内核对象可读取且 SHA 一致，流式读取约 5.71 秒；高级面板对象约 0.35 秒。国内域名库对象原为 404，补齐后独立临时目录恢复并校验约 0.49 秒。没有以删除当前运行文件或再次重启来模拟缺失。

两机备份页首次进入仅查询一次远端记录；桌面与窄屏手动刷新都显示实际版本和包编号；没有周期查询，PID 不变。实际“备份到 WebDAV”按钮均通过，最新索引时间与 SHA 更新；新文件回读 SHA 一致，前一应用备份对象返回 404。原有远端配置未导入设备。

“只保留最新”指每种备份范围的最新应用/配置包；内核、高级面板和规则对象是独立的按 SHA 获取缓存。不能把它们当作多个历史应用备份，也不能在更换应用包时一并删除。

## 自动回归与门槛

根测试 40，AX5 70 Python + 23 JS，K2P 177 Python + 25 JS 通过。原逐文件基线 SHA 不变；改动通过单独的审查列表记录。两处测试驱动问题保留原失败记录：错误引用 inspectBusy，以及 AX5 连续查询的 18 秒等待超时；修正驱动状态名并延长等待后重测通过。单独实际查询返回 12818 条规则、26 个组及当前连接。未据此宣称所有网络异常均已定位。

清单更新为 348 项 / 696 个桌面与窄屏执行位。已执行的正常路径记录为部分通过，未执行、恢复和失败边界继续保留。全量发布门槛仍未满足：干净安装、完整应用恢复、三模式真实 LAN TCP/UDP 全场景、全部动态高级面板操作、AX5 长期断连及 K2P 高连接数 OOM 仍需后续验收。未推送、打标签或发布新的候选版本。

原始页面结果、敏感索引、归档、SHA、网络计数和配置指纹在任务的私有测试记录中，不进入仓库。
