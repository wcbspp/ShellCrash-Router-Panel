# AX5 网站检测修复

腾讯按钮调用 `tencentqq`，但 AX5 后端固定接口列表没有该项，返回 HTTP 400。页面把接口拒绝统一显示成“未连接”，容易误判为代理或网站故障。

已补齐腾讯接口，并统一八个按钮与后端的检测 URL。回归检查比较完整列表，防止新增按钮漏接接口。错误显示区分接口错误、超时、TLS 校验失败和目标返回的 HTTP 错误；HTTP 4xx/5xx 使用黄色提示。

实机通过路由器当前规则发起 HTTPS 请求，未强制指定某个节点。电脑单点腾讯、全部八站检测、390像素手机单点腾讯都已执行。结果：百度200、哔哩哔哩200、腾讯301、淘宝302、Google204、YouTube204、GitHub200；ChatGPT403，正确显示黄色 HTTP 错误。301/302 只证明重定向响应，403 只证明目标响应，不代表网站登录或账号功能可用。

八个检测接口本身全部返回200，页面无脚本错误、电脑和手机无横向溢出。原始截图和响应记录存于本地 private 文件，不进入发布包。

根33项、AX46项与14个JS脚本、K127项与17个JS脚本通过。AX接口与共享页面源逐字节部署回读；K同步错误显示并保存Storage。两机内核PID和配置指纹不变，没有恢复备份或重启。

K2P 网站实机全面检测与 AX5 长期偶发断流仍是单独的未完成项；本次结果不代替那些验收。
