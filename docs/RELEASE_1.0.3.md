# 1.0.3

这版补齐了 AX5 和 K2P 的 OOM 取证保存，也整理了监控页的按钮布局。

- 本地保留最近一次 OOM 记录，写入持久存储；记录路径可在监控页查看。
- 可选开启 WebDAV 远程监控，复用已经配置并验证的连接。上传后回读校验，远程保留历史记录。
- 每分钟采集有界的内存、进程及连接来源摘要，帮助排查故障前后的变化；不记录进程命令行或流量内容。
- 查看、下载与远程监控分组排列，手机窄屏自动换行，长路径不会撑开页面。

两台真机已核对持久化文件、WebDAV 保存和重启后的恢复。AX5 另做了受控内存压力及主动 OOM 测试；K2P 没有主动制造 OOM。桌面和手机宽度的排版已做浏览器截图检查。

## 使用前了解

远程监控默认关闭，需要先配置 WebDAV，再在监控页开启。可用内存低于当前保护阈值、网络中断或管理忙时，采集或保存可能延迟；它不是连续抓包，也不能保证断电前最后一刻的日志完整。K2P 的新记录尚未写入 Storage 时断电，可能丢失本次记录。远程文件不会自动清理，请定期检查 WebDAV 空间。

AX5 的自然 OOM 原因仍在排查，这版不代表已经修复。K2P 本次重启后曾超过十分钟无法远程连接，后续复查服务、节点及代理均正常，恢复延迟原因尚未确定。此前未完成的长期负载与业务边界限制仍按 [1.0 发布记录](RELEASE_1.0.md) 保留。

安装前确认机型和固件，并保留配置备份。在线与离线安装步骤见 [安装说明](DEPLOYMENT.md)。安装包不含用户配置、密码、设备身份、路由器固件或代理内核二进制。
