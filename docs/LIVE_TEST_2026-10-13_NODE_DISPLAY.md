# 基础节点选择显示修正

内核当前路径为“节点选择 → 手动切换 → 台湾02”。“手动切换”是订阅中的中间策略组，原卡片仅显示它，无法让用户确认最终节点。

共享页面改为显示最终节点，完整路径保留在卡片提示中。基础节点按钮仍通过订阅已有的手动组选择，不改订阅的组成员；多个规则共用同一手动组时，选择也会共同变化。网站需要独立固定节点时，可在对应分流卡片选择基础节点。

台湾旗帜改用本地 CSS 的小型 TW 标识；内核实际名称、API 参数及订阅排除匹配不改。卡片、列表、首页和模式状态刷新共用显示入口，避免刷新后重新出现缺字方框。

验证：两机代码回归、部署差异检查；实际页面读取内核最终路径，电脑和390像素手机布局，基础节点视图与同节点点击。AX5 实际路径末端台湾02，K2P 台湾01。实机菜单整体与长期稳定性尚未全部验收，这份记录不代表那些项目已通过。

部署只替换页面文件，逐字节回读；两机内核 PID 和配置指纹保持不变，K2P 写入 Storage。没有恢复备份或提交新订阅。
