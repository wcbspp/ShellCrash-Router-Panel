# On-demand node Ping and HTTPS request time

The node list retains one core HTTPS delay request per node. Clicking its value opens a diagnostic panel with separate actions for router-to-node ICMP Ping and proxy-to-Gstatic HTTPS request time. Opening the panel sends no Ping. Ping and HTTPS execute serially, do not select another node and do not modify routing, DNS, AnyTLS or mihomo unified-delay. ICMP failure means no ICMP response, not an unavailable proxy. IPv6 literals, chained outbounds and absent or ambiguous server mappings are explicitly unsupported.

The authenticated request carries a short node key, never a caller-supplied host. A unique matching server is read from the installed canonical configuration. K2P's existing 58-character command limit is preserved. AX5 uses the bounded JSON object stream parser with a root-array seek; a regression covers a late root outbounds array and a misleading nested array. K2P uses a strict bounded reader and a private derived RAM index (at most 64 KiB), rebuilt when the configuration change token differs. This index contains only opaque keys and server addresses, not passwords or measurement history. No daemon or dependency is added. The stock firmware has neither cksum nor K2P timeout; the implementation uses existing md5sum only as a change token and temporary shell watchdogs. Ping is limited to one packet and four seconds including resolution; first K2P index construction has its own eight-second bound.

The UI binds results to the resolved group path, configuration token and core identity, and expires Ping after two minutes. Low memory and active configuration operations reject probes. Unknown node keys, ambiguous matches and unsupported sources cannot introduce arbitrary destinations. Late results after cancellation do not replace the displayed node. The backend rechecks configuration after the probe. Result history stays in the browser; the native bridge retains one short result object.

Actual desktop browser tests on AX5/mihomo and K2P/sing-box verified entry, actual Ping result, exactly one HTTPS request, unknown-key rejection, closing and 1200/390 px layout. AX5's sampled node did not return ICMP and correctly displayed no response; its HTTPS result was 630 ms. K2P returned 67.772 ms Ping and 463 ms HTTPS. These are individual samples, not averages. Actual AX5 sing-box switching was not repeated during the ongoing observation; both canonical profile cases are covered by parser tests, not claimed as an AX5 switched-core live test.

With the real-page sequence and temporary 50 ms memory sampling, the lowest observed available memory was AX5 16540 KiB and K2P 17764 KiB, above the tested reserve. These samples include instrumentation and other activity; they are not an exact isolated allocation peak or a full OOM test. Two devices' configuration, core PID, boot ID and cron stayed unchanged. Earlier missing-command/parser-deadline failures are retained and are not passed results. The control inventory marks these new controls partially verified because all live boundary and mobile-business combinations were not exercised.
