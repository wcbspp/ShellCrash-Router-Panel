# 国内直连加速

规则页的「绕过国内 IP」让国内 IPv4 连接在防火墙直接放行，减少内核处理。它按目的 IP 判断，使用本机 ShellCrash 国内 IP 表，不按网站名称或国籍判断。

| 设置 | 新连接如何处理 | 首页统计 |
| --- | --- | --- |
| 关闭 | 内核依次处理自定义规则、订阅规则、国内 IP 补充和默认出口 | 内核处理的连接都计入，包括 DIRECT |
| 开启，规则模式 | 国内 IP 提前直连；国外 IP 仍执行当前规则 | 绕过的国内连接不计入 |
| 全局代理 | 暂停绕过，已接管的外网连接使用默认代理组 | 只统计内核接管的流量 |
| 直连上网 | 暂停透明代理接管 | 保留累计，不把它当成当前直连流量 |

**开启后，国内 IP 上的强制代理和拦截规则会被跳过。** 有国外域名的自定义代理规则仍可开启；页面提示这个优先级，不再一律禁止。国外网站也可能使用国内 IP，IP 表也可能存在分类错误；需要严格执行全部域名规则时，请保持关闭。

切换不重启内核，只影响新连接。已有 TCP 会话可能继续使用之前的出口。累计始终是本次内核启动以来处理的全部流量，不会因为改变模式就变成“纯代理用量”，也不等于订阅账单或路由器总流量。

实现使用现有 ShellCrash 防火墙链与国内 IP 表，不新增常驻采集服务。私网、DNS 和内核自身的标记连接先处理；只管理带 `SC_PANEL_CN_BYPASS` 标记的规则。规则模式恢复时重新检查状态；内存或数据校验不足时继续由内核处理，页面区分“已开启”和“实际生效”。纯 Fake-IP 不支持提前绕过。

K2P 使用 Padavan Storage 保存设置。防火墙应用后仍需等待闪存保存，页面显示「已应用，正在保存到闪存」；这一步不是内核重启。新国内 IP 集合建立时保留用户设定的内存保护值，并额外预留 2 MB。

提前直连通常能减少国内连接的内核工作，适合内存紧张的设备。但本轮没有测得 CPU、内存或游戏延迟的改善百分比；防火墙命中计数只能证明路径生效，不能证明游戏延迟降低。
