# 备份与恢复

先备份，再动配置。备份文件可能含订阅和节点密码，请放在自己控制的电脑或服务器，不要上传公开仓库。

## 该保存哪一种

| 文件或记录 | 内容与用途 |
| --- | --- |
| 最新完整备份 | 程序、当时配置、匹配内核和运行资源，供同机型同内核恢复 |
| 自动配置备份 | 配置及必要资源，不能替代完整程序备份 |
| 独立基础备份 | 确认可用的一套完整文件，单独保存；日常滚动备份不覆盖它 |
| 本机应用导出.tar.gz | 程序和配置，内核与临时运行资源需另存 |
| 完整.zip | 清单和全部组件，适合留在电脑或手机；不是刷机包 |
| 电脑安装前快照 | 本次更新前的私有目录，用于原设备回退，可能含远端凭据和链接 |

完整清单引用应用、内核、运行资源三个组件，逐个核对大小和SHA256；只拿到一个应用包，不算完整恢复点。旧format1记录也不能当成完整format2备份。

## 设置WebDAV

默认关闭。填写服务器地址、账号和密码，先测试，成功后保存开启。换参数要重新测试；取消勾选并保存可关闭，原参数会保留。关闭或未验证时，不访问远端备份。

可信内网可用HTTP，公网使用HTTPS。页面显示备份组件、版本、大小与校验值；打开页面不会自动恢复。新完整备份全部上传并回读校验后，才替换最新记录；独立基础目录不随滚动清理删除。

## 从网页恢复

1. 在备份页打开恢复窗口，选择最新完整备份、独立基础备份或已导入的完整备份。
2. 先检查组件。页面校验通过不等于马上写入，设备还要检查机型、内核、当前配置、可用资源和后台是否空闲。
3. 符合条件后查看计划，再二次确认。确认凭据短期有效、只能用一次，过期或设备状态变了就重新检查。
4. 执行时不要再发第二个恢复任务。连接断开后重新打开页面，查询同一任务的结果；不要把网页超时当成恢复失败而重复写入。

当前开放范围是**同机型、同内核**的完整恢复。跨机型、缺组件、不兼容或忙态会被拒绝。本地单文件选择只用于检查，不会把不完整归档直接写进设备。原生恢复工具另见[AX5](AX5_RESTORE_TOOL.md)、[K2P](K2P_RESTORE_TOOL.md)。

恢复执行许可保留本机当前状态，不随备份迁移。备份不包含整机固件、Factory分区、其他插件数据或ZeroTier身份；可导入应用包也排除SSH/WebDAV凭据。电脑安装前快照范围不同，可能含这些凭据，应单独私密保存。

## 重启后用哪个内核

以本机最后成功保存的种类、版本、架构、SHA和来源记录为准：先找匹配本地文件，再用已开启且实际连接正常的WebDAV，最后尝试配置的同版本下载源。旧基础点只有摘要匹配时才可提供文件，不用旧版本覆盖本机记录。

K2P内核运行在RAM，离线首装不意味着以后离线重启都能恢复；要提前准备可访问的匹配备份。下载失败不使用半截文件，原版本记录保留以便重试。手动停止服务或关闭自启后，不会被守护马上强行拉起。
