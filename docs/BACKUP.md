# 备份文件与恢复

WebDAV 默认关闭。测试先验证服务器访问和读写，保存再正式启用；更换地址、用户或密码后需要重测。取消勾选并保存关闭，保留原连接参数。关闭或未验证时不访问备份服务器。

远端分别维护最新应用包、配置包以及按校验值定位的内核/高级面板文件。版本显示来自实际元数据，不将本地版本当作远端版本。备份同步失败单独提示，不撤销本地已经生效的设置。

| 文件 | 内容 | 用途 |
|---|---|---|
| 应用 `.tar.gz` | 应用与配置、`backup.info`、`RESTORE.txt` | 恢复原设备应用与配置 |
| `core-<SHA256>.tar.gz` | 对应架构/版本内核 | 配合应用记录恢复运行程序 |
| 高级面板归档 | 已验证的 YACD/Yacd-Meta | 重启后按需恢复 RAM 网页文件 |

应用包可能含订阅、节点密码和本机配置；WebDAV 登录凭据不放入应用导出。应用包不包含固件与 Factory 分区，不承担硬件身份恢复。传输编码是下载通道的内部处理，客户端最终得到标准 `.tar.gz`，不是 Base64 文本文件。

K2P 使用同文件系统快照和受预算限制的流式压缩；客户端校验长度、SHA256 与 gzip 标识再下载。内存或持久空间不足时保留原文件并反馈，不提供截断包。旧的损坏下载不可用，必须重新导出。

当前没有任意备份上传后一键自动导入。请按 `RESTORE.txt` 对应机型、目录、内核 SHA256 恢复；先保留现用配置，不能跨机型或跨固件直接覆盖。恢复、重启后确认 API、节点选择、分流、DNS 与守护，完整恢复演练是正式发布前门槛。
