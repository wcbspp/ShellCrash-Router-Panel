# 分级本地并发与可复现分发包

两机通过当前HTTP代理入口建立受控本地DIRECT连接，先4/8/16/32，再以8/32/64逐级验证。目标为SSH回环转发连接的电脑临时端点，不发给第三方，不带控制器凭据，只发送审计请求。每级从当前内核连接API核对目标及DIRECT链，并读取可用内存/RSS/PID；配置任务活跃或余量不足即收回。预留线为至少18MiB或当前保护值加4MiB，未降低设备阈值。

最终两机均核对到64条目标DIRECT连接，最低采样可用内存AX5 18688KiB、K2P 18852KiB，均高于18432KiB预留线；最高采样RSS分别40260/36108KiB。配置SHA/PID/boot保持，未切换用户节点、停止或重启内核。这是短时、小流量、本地并发回归，不代表外网高吞吐、持续数百连接、完整OOM或长期验收通过，也不扩大解释为Wi-Fi新实测。

最初空隧道及控制器目标未被连接表观察到，不计通过。旧SSH服务未真正执行cancel远程监听，首次补64因端口占用未开始；该失败保留。已改为结束本任务自建AX/K SSH masters后安全重建，保留云端master及原配置，核对39090/39091审计监听消失；最终64轮的finally也执行此收尾并逐机验证。测试客户端与电脑临时端点关闭，未留下公开监听。此为验证工具传输层的兼容处理，不是路由器应用功能修复。

e3761a0修复后的两机分发包各连续构建两次，SHA逐字一致；解包检查全部条目为正规文件、无绝对路径/父目录跳转，完整MANIFEST逐文件核对通过。AX5 227文件、K2P 320文件。此前dist先另存私有目录，未覆盖旧稳定基础点、未上传或发布。这些名为1.0.0-rc.2的本地验证工件不表示最终RC门槛已通过，最终收尾仍需绑定最终源码重新出包。

私有证据：concurrency-loopback-20261016.private（32级）、concurrency-64-final-20261016.private（64级及transport-cleanup）、package-audit-fixed-20261016.private（绑定e3761a0的两次构建及清单验证）。旧失败目录均保留，不把失败轮当成功。原不同版本升级冷启动、干净设备安装、其余业务与高负载/长期门槛继续待验。
