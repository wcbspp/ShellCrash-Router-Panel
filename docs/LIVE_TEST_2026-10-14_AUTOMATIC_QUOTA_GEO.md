# 自动余量同步与出口归属地

2026-10-14；补充上一轮 IP / 余量记录。本轮没有重启设备、内核，或重新加载服务商订阅。

## 变化

- AX5 的启动就绪与成功订阅加载、K2P 的 ShellCrash afstart 和成功 apply 钩子调度一次余量同步。只访问当前成功加载的原订阅，沿用其 UA，不调用转换服务。
- 启动和订阅成功事件相近时合并；查询等待配置操作结束，完成后退出。内存不足或配置操作久未结束时最长等候约两分钟，然后显示暂缓原因。没有新增常驻服务、cron 或定时服务商查询。
- 成功或失败查询更新运行期缓存版本。面板沿用已有状态轮询感知新版本，只读取缓存并显示最新结果。失败保留同一订阅的上次数据与时间，明确提示“上次查询数据”；不同来源不会继承。
- 页面加载自动检测一次 IP；随后首次进入检测页不重复发请求。刷新页面重新检测，也可手动刷新。切页或隐藏时取消正在进行的检测。
- 国内测试站点使用 IPIP，国外站点使用 IP.SB，并在需要时用 IPify 获取地址。显示实际出口 IP、国家、地区、城市和运营商；IPv6 单列。结果从当前浏览器获取，远程管理页面不等同被管理路由器的出口。IPv6 地址归属地按实际地址另行查询。
- 每个请求六秒、最多四 KB JSON。第三方接口失败不影响网站网络检测；数据库位置仅是查询结果，不代表节点名称或精确物理位置。无法获取时明确显示，不根据“台湾”等节点名称推断。

## 验证

两机真实浏览器分别在 1200 / 390 宽度验证页面自动请求、国内和国外地址及归属地、首次打开检测页不重复、手动刷新、F5 自动重查。无页面错误或横向溢出。国内站点实际返回国内运营商信息，国外站点实际返回境外地址与运营商；原始地址与截图不进入 Git。

两机在现有运行内核下直接派发三次生命周期同步请求，使用只记录请求次数的临时 curl 包装，合并成一次真实服务商 HEAD；同一事件再次派发没有再次查询。两机读取到完整用量数据，内核 PID 和受保护配置指纹不变。测试包装已删除。

离线覆盖更新期间等待、重复事件合并、新内核纪元再次查询、服务异常保留旧数据、切换来源清除、IP / IPv6 验证、JSON 大小限制、归属地显示、一次自动触发及取消。生产启动和成功订阅回调的位置已检查；本轮为了避免多次重启，没有完成新的整套实机重启/订阅事务。执行矩阵继续标记“部分通过”，不把调度实测写成整套生命周期验收。

本记录替代上一轮“IP 与余量只手动查询”的行为描述。余量在生命周期事件自动查询，页面本身只读缓存；IP 在每次页面加载自动查询一轮。资源保护阈值保持 AX5 14 MB / K2P 12 MB，用户设置和海外排除条件均保留。
